# Glosario

| Término | Significado |
|---------|-------------|
| **Placa / tablero** | Panel rectangular de material (melamina, MDF, fenólico…) de formato estándar |
| **Formato** | Dimensiones nominales de una placa (p. ej. 1830 × 2820 × 18 mm) |
| **Pieza** | Rectángulo a obtener de la placa para un mueble |
| **PieceSpec / instancia** | Definición con cantidad / cada pieza individual numerada |
| **Kerf** | Material que consume el disco en cada corte |
| **Refilado / margen** | Franja perimetral que se descarta para obtener bordes rectos |
| **Veta** | Dirección de la fibra o del dibujo del laminado |
| **Corte guillotina** | Corte recto que atraviesa por completo la región actual |
| **Tira** | Franja obtenida en el primer nivel de cortes |
| **Escuadradora** | Sierra de mesa con carro para cortes rectos y escuadrados (solo guillotina) |
| **CNC** | Router de control numérico; puede hacer layouts no guillotinables |
| **Retazo** | Sobrante rectangular reutilizable |
| **Desperdicio** | Sobrante no aprovechable (incluye kerf y refilado) |
| **Aprovechamiento** | Área de piezas / área de placas usadas |
| **Bin packing 2D** | Problema de colocar rectángulos en el mínimo número de contenedores |
| **MaxRects** | Algoritmo de packing basado en rectángulos libres maximales |
| **Guillotine packer** | Algoritmo de packing que divide el espacio libre con cortes guillotina |
| **Cota inferior (LB)** | Número mínimo teórico de placas: ⌈área piezas infladas / área útil⌉ |
| **dmm** | Décima de milímetro, unidad entera interna (1 mm = 10 dmm) |
| **Tapacanto** | Cinta que cubre el canto de la pieza (futuro) |
